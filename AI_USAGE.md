# AI Usage Declaration

## Project: GemGuide – Gemstone Recommendation App

This file documents how AI tools were used during the development of this project.

## AI Tool Used

**Antigravity (Google DeepMind)** — Agentic AI coding assistant

## How AI Was Used

| Area | Usage |
|---|---|
| **Project Scaffolding** | AI initialized the Vite + React project structure |
| **Component Architecture** | AI designed the component breakdown and routing structure |
| **UI/UX Design** | AI created the CSS design system (dark luxury theme, glassmorphism, animations) |
| **Gemstone Data** | AI structured the gemstone dataset with all attributes (zodiac, chakra, planet, etc.) |
| **Recommendation Logic** | AI wrote the `getRecommendations()` function with zodiac + chakra + budget filtering |
| **Zodiac Detection** | AI implemented `getZodiacFromDOB()` helper |
| **All JSX Components** | AI generated all React components (Navbar, GemCard, pages) |
| **All CSS Styling** | AI wrote all CSS including animations, responsive layouts, and design tokens |
| **README** | AI drafted the README with architecture and feature documentation |

## What Was Done Without AI

- Project direction and feature selection (chose Gemstone Recommendation App)
- Feedback on design decisions (approved the dark luxury aesthetic)
- Reviewing and approving the generated code

## Notes

The AI was used as a pair-programming tool under developer supervision. All generated code was reviewed before inclusion. The gemstone attribute data (zodiac associations, chakra mappings, Vedic astrology principles) is based on well-established traditional knowledge.
